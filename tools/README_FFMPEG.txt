Callspire Softphone — ffmpeg

Эта папка предназначена для ffmpeg.exe (опционально).

Зачем:
- Конвертация записей WebRTC/SIP (например webm -> wav) использует ffmpeg.

Как работает:
- Приложение сначала ищет ffmpeg по пути: <папка приложения>\tools\ffmpeg.exe
- Если не найдено — пробует "ffmpeg" из системного PATH.

Что сделать:
1) Скачайте ffmpeg для Windows (ffmpeg.exe)
2) Положите файл сюда: tools\ffmpeg.exe

Важно:
- Этот репозиторий не включает ffmpeg.exe по умолчанию (лицензирование/размер).
