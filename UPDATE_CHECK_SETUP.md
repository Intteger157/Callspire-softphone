# Настройка проверки обновлений

Для работы проверки обновлений необходимо настроить данные вашего GitHub репозитория.

## Шаги настройки:

1. **Откройте файлы для редактирования:**
   - `MainWindow.xaml.cs` - метод `GetRepositoryOwner()` и `GetRepositoryName()`
   - `SettingsWindow.xaml.cs` - метод `GetRepositoryOwner()` и `GetRepositoryName()`

2. **Замените значения:**
   ```csharp
   private string GetRepositoryOwner()
   {
       return "YOUR_GITHUB_USERNAME"; // Замените на ваш GitHub username
   }
   
   private string GetRepositoryName()
   {
       return "YOUR_REPOSITORY_NAME"; // Замените на название вашего репозитория
   }
   ```

   Например:
   ```csharp
   private string GetRepositoryOwner()
   {
       return "username";
   }
   
   private string GetRepositoryName()
   {
       return "softphone";
   }
   ```

3. **Настройте версию в `Callspire.csproj`:**
   Версия уже настроена в файле проекта:
   ```xml
   <Version>1.0.0</Version>
   <AssemblyVersion>1.0.0.0</AssemblyVersion>
   <FileVersion>1.0.0.0</FileVersion>
   ```

## Как работает проверка обновлений:

1. **При запуске приложения:**
   - Через 3 секунды после запуска выполняется автоматическая проверка новой версии
   - Если найдена новая версия, показывается окно уведомления
   - Для приватных репозиториев используется токен из настроек (если указан)

2. **В разделе About:**
   - Пользователь может вручную проверить наличие обновлений
   - Отображается текущая версия приложения
   - Можно ввести GitHub Personal Access Token для приватных репозиториев
   - Токен автоматически шифруется и сохраняется при вводе

3. **Формат версий:**
   - Версии должны быть в формате `x.y.z` (например, `1.0.0`, `1.1.0`, `2.0.0`)
   - GitHub релизы могут иметь префикс `v` (например, `v1.0.0`) - он автоматически удаляется

## Создание релиза на GitHub:

1. Перейдите в ваш репозиторий на GitHub
2. Нажмите "Releases" → "Create a new release"
3. Укажите тег версии (например, `1.0.0` или `v1.0.0`)
4. Загрузите файл `.exe` в раздел "Attach binaries"
5. Опубликуйте релиз

Приложение автоматически найдет последний релиз и сравнит версию с текущей.
