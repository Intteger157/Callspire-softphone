# Настройка GitHub Personal Access Token для приватных репозиториев

Для работы проверки обновлений с приватными репозиториями GitHub необходимо создать Personal Access Token (PAT).

## Шаги создания токена:

1. **Перейдите на GitHub:**
   - Откройте https://github.com
   - Войдите в свой аккаунт

2. **Создайте Personal Access Token:**
   - Нажмите на ваш аватар в правом верхнем углу
   - Выберите **Settings**
   - В левом меню прокрутите вниз и выберите **Developer settings**
   - Выберите **Personal access tokens** → **Tokens (classic)**
   - Нажмите **Generate new token** → **Generate new token (classic)**

3. **Настройте токен:**
   - **Note:** Укажите название токена (например, "Softphone Update Check")
   - **Expiration:** Выберите срок действия (рекомендуется "No expiration" или длительный срок)
   - **Scopes:** Отметьте следующие права:
     - ✅ `repo` (Full control of private repositories) - **ОБЯЗАТЕЛЬНО для приватных репозиториев**
     - Или минимум: `public_repo` (для публичных репозиториев)

4. **Скопируйте токен:**
   - Нажмите **Generate token**
   - **ВАЖНО:** Скопируйте токен сразу, так как он больше не будет показан!
   - Токен выглядит примерно так: `ghp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`

5. **Вставьте токен в приложение:**
   - Откройте приложение
   - Перейдите в **Settings** → **About**
   - Вставьте токен в поле **"GitHub Personal Access Token"**
   - Токен автоматически зашифруется и сохранится при вводе
   - Токен хранится в зашифрованном виде (AES-256) в файле настроек

## Безопасность:

- ⚠️ **НЕ делитесь токеном** с другими людьми
- ⚠️ **НЕ публикуйте токен** в публичных репозиториях или коде
- ⚠️ Если токен скомпрометирован, немедленно удалите его на GitHub и создайте новый
- ✅ Токен хранится локально в файле настроек приложения в зашифрованном виде (AES-256)
- ✅ Токен автоматически шифруется при сохранении и расшифровывается только при использовании
- ✅ Для публичных репозиториев токен не обязателен (можно оставить поле пустым)

## Проверка работы:

1. После ввода токена нажмите **"Check for Updates"**
2. Если токен правильный, проверка должна пройти успешно
3. Если репозиторий приватный и токен не указан, вы получите ошибку 404

## Устранение проблем:

- **Ошибка 401 (Unauthorized):** Токен неверный или истек срок действия
- **Ошибка 403 (Forbidden):** У токена недостаточно прав (нужно право `repo`)
- **Ошибка 404 (Not Found):** Репозиторий не существует или токен не указан для приватного репозитория
