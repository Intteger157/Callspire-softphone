# Регистрация протокола callspire:// для интеграции с AmoCRM

## ✅ Автоматическая регистрация (встроена в приложение)

**Протокол регистрируется автоматически при первом запуске приложения!**

Приложение автоматически проверяет и регистрирует протокол `callspire://` при запуске, если он еще не зарегистрирован. Регистрация происходит в `HKEY_CURRENT_USER` и **не требует прав администратора**.

### Как это работает:

1. При первом запуске приложение проверяет, зарегистрирован ли протокол
2. Если протокол не зарегистрирован, он автоматически регистрируется
3. Регистрация происходит в фоновом режиме, не блокируя запуск приложения
4. Логи регистрации можно увидеть в окне логов приложения

### Проверка регистрации:

- Откройте окно логов в приложении
- Найдите сообщения вида `[ProtocolRegistrar] Protocol callspire:// registered successfully`
- Или проверьте вручную через реестр: `HKEY_CURRENT_USER\Software\Classes\callspire`

---

## Ручная регистрация (если автоматическая не сработала)

Если по какой-то причине автоматическая регистрация не сработала, можно зарегистрировать протокол вручную:

### Вариант 1: Через файл .reg

Создайте файл `register_protocol.reg` со следующим содержимым (замените `ПУТЬ_К_ПРИЛОЖЕНИЮ` на реальный путь к exe файлу):

```reg
Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Classes\callspire]
@="URL:Callspire Protocol"
"URL Protocol"=""

[HKEY_CURRENT_USER\Software\Classes\callspire\shell]

[HKEY_CURRENT_USER\Software\Classes\callspire\shell\open]

[HKEY_CURRENT_USER\Software\Classes\callspire\shell\open\command]
@="\"ПУТЬ_К_ПРИЛОЖЕНИЮ\\Callspire.exe\" \"%1\""
```

Запустите этот файл для регистрации протокола.

### Вариант 2: Через редактор реестра

1. Откройте редактор реестра (regedit.exe)
2. Перейдите в `HKEY_CURRENT_USER\Software\Classes`
3. Создайте новый ключ `callspire`
4. Установите значение по умолчанию: `URL:Callspire Protocol`
5. Создайте строковый параметр `URL Protocol` со значением `""` (пустая строка)
6. Создайте структуру: `callspire\shell\open\command`
7. Установите значение по умолчанию для `command`: `"путь_к_приложению\Callspire.exe" "%1"`

## Использование в AmoCRM

После регистрации протокола в AmoCRM можно использовать ссылки вида:

```
callspire://call?phone=17027325111&leadId=12345
```

Где:
- `phone` - номер телефона для звонка
- `leadId` - ID лида в AmoCRM (опционально)

При клике на такую ссылку в браузере AmoCRM приложение Callspire откроется и инициирует звонок на указанный номер. После завершения звонка запись разговора или карточка недозвона будет автоматически загружена в указанный лид.

---

## Технические детали

- Регистрация происходит в `HKEY_CURRENT_USER` (не требует прав администратора)
- Протокол регистрируется для текущего пользователя Windows
- При обновлении приложения регистрация сохраняется (проверяется путь к exe)
- Если путь к exe изменился, протокол будет перерегистрирован при следующем запуске
